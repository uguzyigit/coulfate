# NopCommerce 4.90 Plugin Development Instructions

## Automatic Workflow for Plugin Development

When I request plugin development or modifications, Claude should:

### 1. ALWAYS Read Documentation First
```bash
# Required reading order:
view /Users/piqmacbook/Projects/nopcommerce-4.90/README.md
view /Users/piqmacbook/Projects/nopcommerce-4.90/docs/DEVELOPMENT_GUIDE.md
view /Users/piqmacbook/Projects/nopcommerce-4.90/docs/ARCHITECTURE.md

# If database work:
view /Users/piqmacbook/Projects/nopcommerce-4.90/docs/DATABASE.md

# If existing plugin:
view /Users/piqmacbook/Projects/nopcommerce-4.90/src/Plugins/[PluginName]/README.md

# If errors:
view /Users/piqmacbook/Projects/nopcommerce-4.90/docs/TROUBLESHOOTING.md
```

### 2. Follow These Rules

- ✅ Use MySQL syntax (IFNULL not ISNULL, LIMIT not TOP, backticks for tables)
- ✅ Use templates from DEVELOPMENT_GUIDE.md
- ✅ Follow Core-based architecture from ARCHITECTURE.md
- ✅ Check TROUBLESHOOTING.md for known issues
- ✅ Always use `view` tool to read documentation before coding

### 3. Response Format

Always structure responses as:

1. **"Reading documentation..."** (show what you're reading)
2. **"Plan:"** (what you'll do based on docs)
3. **"Implementation:"** (step-by-step with bash commands)
4. **"Testing:"** (how to verify)
5. **"Next Steps:"** (what user should do)

### 4. Key Paths
```
Project: /Users/piqmacbook/Projects/nopcommerce-4.90
Docs: /Users/piqmacbook/Projects/nopcommerce-4.90/docs/
```

```bash

# Clear cache

# Check logs

```
